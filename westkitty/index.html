01 / OPERATING THESIS

Three verbs.
No decorative bullshit.

Build. Make. Ship. The old profile had the right bones. This is what those bones actually mean.

BUILD

If an idea matters, it should become operable.

Not a mood board. Not a pitch. Something a person can touch, break, understand, and use again tomorrow.

MAKE

Interfaces are arguments.

Hierarchy, latency, defaults, motion, labels, failure states: every one of them tells the user what the system believes matters.

SHIP

Finished means survivable.

A thing is not finished because it renders. It is finished when it can be resumed, repaired, handed off, and still tell the truth about its own state.
